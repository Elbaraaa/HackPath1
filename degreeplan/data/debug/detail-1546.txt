ARCE550 - Building Data Analytics, Visualization, and Management
Civil & Arch Engr & Mechanics  Graduate  UA - UA General 
General
Course ID
043672
Course Description
This course provides a variety of data analytics, visualization, and management (DAVM) techniques using building-associated data (housing; occupants; and building systems (e.g., heating, ventilation, and air-conditioning (HVAC))). Students will acquire an integrated set of concepts, knowledge, principles, and skills to build a rich database, identify patterns via data analytics and/or visualization, and extract valuable knowledge from building-associated data. To this end, students will become an independent thinker that seeks solutions through data and its scientific analyses. This course will primarily use widely accessible or publicly available DAVM tools and programming languages, including Excel, Python, MySQL, and GitHub.
