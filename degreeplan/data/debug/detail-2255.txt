BAT205 - Engineering Analytics and Problem-Solving using Python
Biosystems Engineering  Undergraduate  UA - UA General 
General
Course ID
005651
Course Description
The course will combine Microsoft Excel and the Python programming language to solve Biosystems Engineering problems and statistics using data analytics and problem-solving techniques. This course will use computer-based training to learn and master the use of Microsoft Excel. Python programming will cover objects, objects types, graphics user interfaces (GUIs), sequences, stings, lists, dictionaries, coding user-defined functions, decision structures, loop structures and Booleans, classes, simulation and design, object-oriented programming (OOP), and using Python libraries. Special topics related to data collections, exploring data, packages, prediction and analytics tools, and data over the internet will be introduced.
