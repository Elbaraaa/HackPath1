BAT247 - Introduction to Sensors and Controls
Biosystems Engineering  Undergraduate  UA - UA General 
General
Course ID
041704
Course Description
In this course, electric circuit variables will be presented and defined. Circuit elements and their basic components will be discussed and used to build different circuits. Resistors will be used to build and analyze simple circuits. Operational amplifiers will be discussed and analyzed in simple circuits. Homework activities include hands-on circuit design, building, and analysis. A project to build a circuit using circuit elements and a Raspberry Pi is required.
