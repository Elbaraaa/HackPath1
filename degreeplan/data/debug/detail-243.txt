ACCT528 - Taxation of Partnerships
Accountancy, Sch of  Graduate  UA - UA General 
General
Course ID
005868
Course Description
The purpose of this class is to provide the student with a basic knowledge of how partnerships are taxed for federal income tax purposes. In addition, students will gain some knowledge of a computer based research tool and learn how to prepare a partnership tax return using a computer based tax return preparation program.
