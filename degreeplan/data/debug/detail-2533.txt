BME225 - Introduction to Computer Programming for Biomedical Engineering
Biomedical Engineering  Undergraduate  UA - UA General 
General
Course ID
042265
Course Description
This course provides an introduction to the foundation, knowledge, skills and application of computer programming that is used in biomedical engineering studies. A series of lectures, hands-on coding and experimental sessions will be offered through the format of three workshops (5-weeks for each): 1) C language and analog biomedical signal recording, 2) Python in Jupyter notebook interface for digital biomedical signal recording, 3) Matlab for biomedical signal and image processing.
