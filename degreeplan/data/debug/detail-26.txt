CSC382 - Software Development in C++
Computer Science  Undergraduate  UA - UA General 
General
Course ID
040219
Course Description
This course will build upon students' knowledge of C to become proficient at programming in C++. Topics include testing, classes, templates, inheritance, operator overloading, object-oriented design, the Standard Template Library (STL), and event-driven programming with graphical user interfaces. This course also examines features of the newer versions of C++.­ The course includes a large team project at the end of the semester.
