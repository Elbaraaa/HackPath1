CMM522 - Crash Course in Bioinformatics for Biologists
Cellular & Molecular Medicine  Graduate  UA - UA General 
General
Course ID
042436
Course Description
This course aims to equip graduate students with the basic tools necessary to tackle modern bioinformatic analysis. The goal is to provide foundational concepts that apply to a variety of fields, though the instructors own background in genomics will undoubtedly present a bias.

The course will cover these major topics: High Performance Computing (emphasizing the resources available through the UA HPC), Command line programming (bash/grep/awk/etc.), Code version control (Git/Github), Tools for troubleshooting (Biostars/Stack Overflow), R programming, Python programming

Bioinformatics is best learned through experiential education. Therefore, most of the course will be dedicated to hands-on experience. Lectures will be limited to essential overviews, and most of the course will involve in-class assignments for individual or small group learning.
