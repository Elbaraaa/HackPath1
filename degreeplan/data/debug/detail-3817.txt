CSC337 - Web Programming
Computer Science  Undergraduate  UA - UA General 
General
Course ID
036362
Course Description
Introduction to the techniques and technologies for developing dynamic web sites. This course covers both client-side and server-side development. Client-side development will include HTML, CSS, Javascript, and AJAX. Server-side development will include web server development, deployment and integration with a DMBS. Other topics covered include: security concerns for web applications, password salting and hashing, and domains. This course includes a team project to deploy a web application.
