CYBV267 - Introduction to Compiled Languages
Applied Science  Undergraduate  UA - UA General 
General
Course ID
043571
Course Description
This course will introduce students to logic and problem-solving using the C programming language. The course will build on the foundations of programming and compiled languages while solving real-world problems and creating practical applications. The course will provide a solid foundation of problem solving, algorithm development, design and programming concepts. This course will incorporate the use of sequential, selection, and repetition structures, focus on the programming principles of modularity and simplicity, and utilize single and multi-dimensional arrays.
