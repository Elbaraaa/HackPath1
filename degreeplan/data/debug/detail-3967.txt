Course Description
CYBV 310 provides students with an introduction to C programming. Students will use hands-on exercises to practice and implement applications developed in the C programming language on x86 processors. Students will learn how to write business applications as well as small utility programs. Students will gain a good grasp of debugging and how to perform error handling and build larger applications.
