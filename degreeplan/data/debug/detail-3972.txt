CYBV330 - Introduction to Industrial Control System Security
Applied Science  Undergraduate  UA - UA General 
General
Course ID
041832
Course Description
CYBV 330 is an introduction to Industrial Control Systems (ICS) and what ICS devices do, what applications these devices solve and how these devices are configured. Students will go over the vulnerabilities in these devices and will be able to describe why ICS devices are vulnerable, what cyber security professionals can do to protect this critical infrastructure and how one solution does not fit all. This class will describe the use and application of industrial Programmable Logic Controllers (PLC)s and describe the various components in industrialized control systems.
