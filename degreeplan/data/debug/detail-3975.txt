CYBV382 - Network Forensics
Applied Science  Undergraduate  UA - UA General 
General
Course ID
041325
Course Description
CYBV 382 provides students with in depth knowledge conducting a forensic investigation focusing on network attacks. This course will focus on core concepts of network forensics, coding, network forensic tools, and methodologies for conducting forensic investigations. Students will explore statistical flow analysis, network enumeration, tunneling and encryption and malware detection to support investigations.
