CYBV477 - Advanced Computer Forensics
Applied Science  Undergraduate  UA - UA General 
General
Course ID
039502
Course Description
An advanced forensics course that provides students an in-depth knowledge of network forensics, network flow analysis, network intrusion detection systems, event reconstruction and memory forensics for Windows, Linux and MAC operating systems.
