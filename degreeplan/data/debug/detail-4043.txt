DATA366 - Introduction to Multivariate Statistics
Mathematics  Undergraduate  UA - UA General 
General
Course ID
042830
Course Description
This course covers statistical methods used for analysis of data sets that contain more than one variable. Topics include multivariate normal distribution, covariance, inference about a mean vector, MANOVA, regression, and classification.
