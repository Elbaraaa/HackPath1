DATA470 - Data Visualization
Mathematics  Undergraduate  UA - UA General 
General
Course ID
042885
Course Description
Foundation in the principles of data visualization, particularly as applied to technical data. Hands-on experience using modern software tools for developing visualizations. Topics will include an overview of visual perception, color theory and practice, different types of graphs and their purposes, visualizations for specialized forms of data including time-series and geospatial data sets, strategies for working with multidimensional data, etc. Ethical issues surrounding data visualization. Introduction to visualization using R's ggplot and Shiny.
