AME209 - Computer Programming in Aerospace and Mechanical Engineering
Aerospace & Mechanical Engr  Undergraduate  UA - UA General 
General
Course ID
042709
Course Description
Students will be introduced to the MATLAB and Python programming environments. Concepts including 1D and 2D arrays, creating and running script files, 2D and 3D plots, functions, programming elements including logic statements and loops, curve fitting, interpolation, solving a nonlinear equation with one variable, and finding the maximum or minimum of a function will be covered in MATLAB. Concepts covered in Python include the Python shell, Python objects, control flow, file input/output, functions, and plotting.
